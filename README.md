# 💫 About Me:
Hi, I’m Aarin Kachroo, a full-stack developer with a strong focus on building scalable, high-performance frontend applications.

I specialize in developing responsive, component-driven UIs using React and React Native, with experience translating complex UI/UX designs into production-ready code. I enjoy building reusable frontend architectures, optimizing rendering performance, and ensuring seamless integration with backend systems.

Alongside frontend development, I bring working knowledge of backend systems, APIs, and authentication workflows, enabling me to build end-to-end features with a strong understanding of system design.

## 🔧 What I Work On
- Building scalable and reusable UI components  
- Developing responsive, high-performance web applications  
- Optimizing frontend rendering and state management  
- Integrating REST APIs and handling data flow efficiently  
- Collaborating across frontend, backend, and design systems  

## 🚀 Experience Highlights
- Built authentication UI modules, dashboards, and MFA flows using React in a large-scale system at NIC  
- Developed a CRM frontend with reusable components and optimized rendering, reducing UI duplication by 25%  
- Integrated 15+ APIs and ensured smooth frontend-backend communication across applications  
- Built responsive dashboards and mobile apps using React and React Native
